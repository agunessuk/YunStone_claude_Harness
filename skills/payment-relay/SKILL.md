# 결제·알림톡 중계 서버

근거: 학원 학생관리(내부망 전용)에 이니시스 결제와 알리고 알림톡을 붙이는 설계안 v2, 중계 서버 보안 점검, 이니톡결제 비교 검토.

## 기본 자세
- 사용자가 "아직 작업하지 말고 조사·설계만"이라고 하는 경우가 많다. 그러면 **문서만** 만들고 코드·커밋을 하지 않는다.
- 법·요율·단가는 바뀐다. 숫자마다 출처와 확인 날짜를 붙이고, 확인 못 한 것은 **미확인**으로 표시한다.
- 사용자는 개발자가 아니다. "도메인을 산다는 게 무슨 말이야?" 같은 질문에는 비유 없이 무엇을, 어디서, 얼마에, 누가 관리하는지로 답한다.

## 표준 구조 (먼저 이 그림으로 설명)
- 업무 프로그램(학생 DB)은 **지금처럼 내부망에만.** 바깥과 통하는 일(학부모 결제 화면, PG 결과 받기, 알림톡 발송)은 **클라우드 국내(서울) 리전 소형 서버 1대(중계 서버)**가 맡는다.
- 내부 서버가 중계로 **나가는 연결만** 한다(1분마다 + 버튼). 중계는 내부 서버를 부를 방법이 없다. 공유기 포트를 열지 않는다.
- 중계 서버에 학생 DB를 두지 않는다. 청구서는 무작위 번호·금액·항목·기한·**가린 이름**("김○수")만.
- 카드번호는 PG 결제창 안에서만. 우리 쪽은 가려진 번호만 받는다.
- 중계는 FastAPI + SQLite를 **도커**로 묶고, HTTPS는 **Caddy + Let's Encrypt** 자동 발급·갱신. 해외 리전은 쓰지 않는다(개인정보 국외 이전 고지가 따로 필요).
- 원장의 결제 관리(수납 현황·환불)만 중계의 `/admin`에서 어디서나: 비밀번호 + 인증앱 2단계, 환불마다 재확인.

## 자주 나오는 질문에 대한 답 (근거 포함해 답할 것)
| 질문 | 답의 요지 |
|---|---|
| 도메인을 사야 하나 | HTTPS 인증서와 PG 신청서의 홈페이지 주소에 필요. 연 2만 원 안팎, 자동 연장 + 카드 유효 유지 |
| 무료 인증서로 괜찮나 | 암호화 강도는 유료와 같다. 법은 '안전한 암호화'를 요구할 뿐 유료를 요구하지 않는다 |
| 클라우드가 꼭 필요한가 | 집·학원 PC로도 되지만 고정 IP·상시 전원·포트 개방이 필요하고 학원망이 바깥에 열린다. 월 1만 원 안팎 서버가 관리·보안·안정성 모두 낫다 |
| 링크를 짧게(24시간) 하면 서버를 덜 먹나 | 서버는 어차피 상시 켜짐·정액이라 부담은 같다. 짧은 기한은 **보안용**. 기본은 납부 기한(7일) |
| 바깥에서 학생관리 접속 | 범위 밖으로 둔다. 필요하면 별도 설계(VPN 등)로 |

## 비용 계산 (사용자가 꼭 묻는다)
자세히: [references/cost-and-legal.md](references/cost-and-legal.md)
- 운영비(서버·도메인·알림톡·PG 연관리비·면허세)와 **카드 수수료**를 나눠 표로. 큰돈은 카드 수수료다.
- 매출은 사용자가 준 실제 단가로: 과목별 수강료 × 수강 건수 − 할인(동시 수강·형제). DB의 원생·수강 수를 세어 쓴다.
- 온라인 카드 비율(예: 80~90%)과 매출 구간별 우대 요율로 월 수수료 범위를 낸다. 요율이 언제 바뀌는지(반기)도 적는다.

## 보안 점검
자세히: [references/security-checklist.md](references/security-checklist.md). 중계 코드를 만들었으면 이 표로 점검하고, 찾은 빈틈을 고친 뒤 테스트를 더한다. 커밋은 사용자 허락 뒤.

## PG 신청 준비
- 신청서의 홈페이지 주소는 **실제 운영 사이트**여야 한다(블로그·데모 불가인 경우가 많음 → 업체에 확인). 중계 첫 화면에 상호·대표자·사업자번호·주소·연락처·약관·**환불 규정**을 둔다. 테스트 모드 띠는 첫 화면에 보이지 않게.
- 필요 서류·절차는 업체 신청 페이지를 그날 읽고 정리한다(통신판매업 신고 필요 여부 포함).
- 업체 상담 글은 [templates/pg-inquiry.md](templates/pg-inquiry.md) 틀로: 우리 상황 3줄 → 비교해 달라는 항목 표 → 받고 싶은 답. 상담원이 요구하는 칸(MID, 사업자번호, 문의자, 연락처)은 비워 두고 사용자가 채우게 한다.
- 업체가 간편 상품(예: 이니톡결제처럼 알림톡 링크 결제)을 권하면, 수수료·가입비·링크 유효시간·PC 결제·자기 채널 사용 여부를 우리 설계와 표로 비교해 판단을 붙인다.

## 사람이 해야 하는 일 (Claude가 대신하지 않음)
PG 가입·계약, 카카오 채널·알림톡 템플릿 검수 신청, 도메인 구입, 클라우드 계정(원장 명의 + 2단계 인증) 만들기와 결제, 비밀 키 입력. Claude는 순서·화면 이름·입력값을 안내문으로 만든다.
