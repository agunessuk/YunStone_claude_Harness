# PG·알림톡 업체 상담 글 틀

짧게 쓴다(상담원이 한 화면에 읽게). 업체가 먼저 요구한 칸은 맨 위에 두고 **사용자가 채운다**(Claude는 값을 지어내지 않는다).

```
[문의자 정보]
- MID: (있으면)
- 사업자번호:
- 문의자 성함:
- 연락처:

[문의 내용]
안녕하세요. ○○ 학원(개인사업자)입니다. 학부모에게 매달 교습비를 온라인 카드 결제로 받으려 합니다
(원생 약 ○○명, 월 약 ○○건, 월 결제액 약 ○,○○○만 원, 신용카드·간편결제만).

(상품 A)와 (상품 B) 중 어느 쪽이 맞을지 고민 중이라, 아래 항목으로 비교해 주시면 감사하겠습니다.

| 항목 | 상품 A | 상품 B |
|---|---|---|
| 가입비·연관리비 | | |
| 카드 수수료(영세·중소 우대 적용 여부) | | |
| 결제 링크 유효 기간 | | |
| PC에서 결제 가능 여부 | | |
| 학원 자체 카카오 채널로 안내 가능 여부 | | |
| 환불(부분 환불) 방법 | | |
| 정산 주기 | | |

또한 신청서의 홈페이지 주소로 (결제 전용 사이트 / 블로그)를 써도 되는지 알려 주세요.
감사합니다.
```

## 쓸 때
- 상품 이름은 업체가 쓰는 이름 그대로(예: 이니톡결제 / 표준결제(자체 결제 페이지 연동 + INIAPI 환불)).
- 숫자(원생 수, 건수, 결제액)는 설계 문서의 어림 계산에서 가져오고, 사용자가 확인한 값만 쓴다.
- 비교 항목은 우리 설계에서 실제로 갈리는 것만 남긴다.
