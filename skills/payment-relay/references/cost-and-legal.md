# 비용 계산과 행정 준비

숫자는 2026-11 학원 설계 때 조사한 값이다. **다시 쓸 때는 반드시 그날 다시 확인**하고, 확인 못 하면 미확인으로 둔다.

## 운영비 표 틀 (카드 수수료 제외)
| 항목 | 내는 방식 | 2026-11 조사값 | 한 달로 나누면 |
|---|---|---|---|
| 중계 서버(클라우드 서울, 메모리 1GB급) | 매달 | 7천~1.5만 원 | 7천~1.5만 원 |
| 알림톡 | 선불 충전, 쓴 만큼 | 알림톡 6.5원, 대체 SMS 8.4원, 대체 LMS 25.9원(부가세 포함 여부 미확인) | 건수 × 단가 |
| 도메인 | 1년 | 약 2만 원 | 약 1,700원 |
| PG 연관리비 | 1년 | 0~11만 원 | 0~9,200원 |
| 통신판매업 등록면허세 | 1년 | 수만 원(미확인) | 약 3천 원 |
| 클라우드 자동 스냅샷 백업 | 매달 | 몇백~천 원대 | |

알림톡 예: 200명 × 월 10건 = 2,000건 → 전부 성공 13,000원, 10% 대체 LMS면 약 16,900원.

## 카드 수수료
- PG 기본 요율은 신용카드 3%대(부가세 별도)지만, 영세·중소 사업자는 PG를 써도 **우대 수수료** 적용(신규는 처음 기본 요율 → 선정 후 차액 환급).
- 매출 구간별 우대 요율(2026-11 조사, 재확인 필요): 연 3억 이하 신용 0.40%/체크 0.15%, 3억~5억 1.00%/0.75%, 5억~10억 1.15%/0.90%, 10억~30억 1.45%/1.20%. PG 수수료는 여기에 PG 몫이 더해질 수 있다.
- 구간이 바뀌어도 요율은 즉시가 아니라 **반기마다** 재산정된다.

## 매출 어림 계산 순서
1. DB에서 과목별 수강 건수(재원생만)를 센다.
2. 사용자가 준 수강료(예: 영어 28만, 수학 30만)를 곱한다.
3. 할인: 두 과목 동시 수강 5%, 형제 할인 등(사용자에게 받은 규칙 그대로).
4. 연 매출로 바꿔 구간을 정한다.
5. 온라인 카드 비율(사용자 가정, 예: 80~90%) × 요율 → 월 수수료 범위.
6. 운영비를 더해 "카드 수수료 포함 월 약 OO만 원"으로 한 줄 결론.
- 사용자가 "그건 중요하지 않아, 대략 금액만"이라고 하면 세부 시나리오를 더 늘리지 않는다.

## 행정·법 확인 목록 (조사 대상, 그날 확인)
- 통신판매업 신고: 온라인으로 대금을 받는 학원이 신고 대상인지, 면허세.
- 개인정보: 처리방침에 PG·알림톡 업체를 위탁사로 적기, 국내 리전 서버, 결제 기록 보관 기간(전자상거래 기록 5년 등).
- 교습비 게시·환불 규정(학원법)과 결제 페이지 환불 규정 문구가 서로 맞는지.
- PG 심사: 홈페이지 필수 표시 항목, 업종 제한 여부.
