# 인쇄용 표지

디자인 방향이 아직 없으면 먼저 `design-drafts`로 시안을 고른다. 이 스킬은 **고른 디자인을 인쇄 가능한 파일과 다시 쓸 수 있는 틀로** 만드는 단계다.

## 먼저 정할 것 (모르면 기본값으로 진행하고 보고에 적는다)
| 항목 | 기본값 | 묻는 이유 |
|---|---|---|
| 출력 방식 | 학원 프린터 **A4 낱장**(앞 1장, 뒤 1장) | 인쇄소 제본이면 도련·책등이 필요 |
| 쪽 | 앞표지, 뒤표지 | 속표지·목차·간지가 필요한지 |
| 문구 | 반, 큰 제목, 범위, 학원명 | 같은 틀로 반·제목만 바꿔 여러 판을 낸다 |
| 시리즈 | 기존 시리즈와 **겹치지 않게** | 같은 학원 다른 교재와 헷갈리지 않게 |

## 인쇄 규격
- **A4 낱장:** 210×297mm, 여백 0, 도련 없음. 글은 가장자리에서 10mm 안쪽.
- **인쇄소용:** 사방 3mm 도련(재단 후 잘려 나갈 부분까지 바탕을 늘림) → 216×303mm. 글·로고는 재단선에서 5mm 이상 안쪽. 펼침(뒤+책등+앞)이면 책등 폭은 인쇄소에 쪽수·종이로 물어 정한다.
- 본문 제본 여백: 펼쳤을 때 안쪽 글자가 먹히면 안쪽 여백을 5mm 더 준다(짝수·홀수 쪽 좌우가 반대).
- PDF는 글꼴을 넣어서(embedded) 만든다. 보낸 뒤 다른 PC에서 글꼴이 바뀌지 않게.

## 다시 쓸 수 있는 틀 (`templates/`)
사용자는 인디자인·코드를 만지지 않는다. 그래서 표지는 **문구 파일 + 더블클릭**으로 넘긴다.
| 파일 | 하는 일 |
|---|---|
| `표지문구.txt` | 사용자가 메모장으로 고치는 유일한 파일. `반 = "고2B"` 꼴, 비우면 그 줄이 빠짐 |
| `표지.html` | 디자인 본체. `@page`로 판형, `#front`·`#back`으로 한 쪽씩, 긴 글은 폭에 맞게 자동 축소 |
| `표지_PDF_만들기.bat` | 크롬/엣지 headless로 `표지_앞.pdf`·`표지_뒤.pdf` 생성 |
| `fonts/` | 쓴 글꼴 파일을 함께 넣는다(다른 PC에서도 같은 글꼴). 글꼴 사용 허락 범위를 확인한다 |

틀을 쓸 때:
1. `templates/`를 출력 폴더로 **복사**한다(원본 틀은 그대로).
2. `표지.html`의 색·위치·로고 SVG를 고른 디자인대로 바꾼다. 숫자(mm·pt)는 CSS 맨 위에 모아 둔다.
3. `fonts/`에 글꼴 파일을 넣고 `@font-face` 경로를 맞춘다.
4. `.bat`을 **실제로 실행**해 PDF가 생기는지, 판형(mm)이 맞는지, 글꼴이 들어갔는지 확인한다.
5. 임시 복사본에서 긴 제목으로 바꿔 다시 뽑아 자동 축소가 되는지 본다.
- 같은 디자인의 다른 판("기초 유형"판)은 폴더를 통째로 복사해 따로 둔다. 원래 판은 건드리지 않는다.

## 로고
- 받은 로고 그림이 작으면 크게 쓸 때 흐려진다. 원본 위에 겹쳐 맞춰 보며 **SVG 선으로 다시 그린다.**
- 큰 로고는 선을 1.3~1.5배 굵게 한 판을 따로 만든다. 선끼리 붙지 않게 간격·구멍을 고친다. 작은 로고는 원래 굵기.
- 사용자가 "로고는 학원명만"이라고 하면 심볼을 빼고 글자만 남긴다.
