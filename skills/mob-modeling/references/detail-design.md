# 부품 보강 설계 (make_detail.py · kitbash.py)

목표는 큐브 수가 아니라 **기준 모델 옆에 섰을 때 같은 게임처럼 보이는 실루엣과 재질 구분**이다.
Blockbench 가이드: 알아볼 수 있는 한 요소는 적게, 둥근 물체는 요소 하나로. 기준 모델(해골)은 큐브의 절반쯤이 얇은 판이다.

## 1. 설계 전에 볼 것 (순서대로)
1. **뼈 트리**: `blender-motion/scripts/inspect_model.py <모델>` — 뼈가 부모·자식으로 이어졌는지, 형제인지.
   형제 구조(머리·몸·팔·다리가 모두 루트 아래)면 **몸에 붙인 긴 천을 다리가 뚫는다** → 다리 부품은 다리 뼈에.
2. **동작 범위**: 각 뼈가 공격·등장·사망에서 몇 도 도는지(`inspect_model.py --keys <동작>`, 또는 bbpose 로 샘플링).
   기준점에서 멀리 뻗은 부품일수록 많이 휩쓴다(거리 × sin각). 다리 −61° 면 기준점 아래 10칸 부품이 앞으로 8~9칸 움직인다.
3. **겹칠 자리**: 기존 큐브 면과 같은 평면(같은 좌표)에 새 면을 두면 깜박인다(z-fighting). 1칸 띄우거나 그 면을 `skip`.
   얇은 판(두께 0.025 같은 것)이 있는 자리를 특히 본다.
4. **원래 주요 색**: 설계 파일 `build(kit)` 안에서 `print(kit.colors())` — 재질 기준색은 여기서 고른다. 포인트 색은 1개.
5. **이 몹의 정체**: 이름·던전 테마·공격 패턴(무기 뼈, 손에 든 것, 마법 위치). 패턴이 정해져 있으면 필요한 부위가 정해진다.

## 2. 무엇을 더하나 (멀리서 읽히는 순서)
1. **머리 실루엣**: 두건·투구·뿔·왕관·후드 끝. 머리는 가장 많이 보는 곳.
2. **어깨·팔**: 어깨 판, 넓은 소매(위는 좁고 아래는 넓게 두 단), 팔찌·족쇄.
3. **허리·다리**: 치마·찢어진 천(반쪽씩 다리 뼈에), 허리띠·감개, 늘어진 천 판.
4. **손에 든 것**: 무기·등불·책·지팡이. 공격 동작에서 함께 휘두르므로 손잡이를 쥔 모양이 자연스럽다(매단 물건은 막대처럼 뻗는다).
5. **작은 포인트**: 빛나는 눈·보석·불 1곳. 색 포인트가 많으면 산만하다.
기준: 사람형·갑옷형은 높이 1블록당 큐브 20개 이상(기준 모델 30~42). 슬라임·불꽃처럼 단순함이 의도면 라인업으로 판정.

## 3. kitbash API
```python
kit.material("robe", "#9aa6a9", half=0.25, center=0.68)    # 기준색, 계단 폭(OKLab 밝기 ±), 중심 밝기
kit.cube(뼈, [x,y,z], [x,y,z], 재질, 종류, 이름, skip=[면], rot=("x", -22.5), opts=dict(...))
kit.mirror_x(...)                                           # x 를 뒤집은 짝 (east/west skip 도 바뀜)
kit.colors(8)                                               # 원본 주요 색 [(hex, 비율, 밝기)]
```
- 좌표는 정수만(아니면 멈춤: 믹셀 방지). 회전은 한 축 0·±22.5·±45 만(아니면 멈춤). 두께 0 판은 앞뒤 면만 생긴다.
- `skip`: 안 보이는 면(안쪽, 맞닿는 면, 열린 아래)에는 텍스처를 주지 않는다 → 깜박임·낭비 방지.
- 부품 텍스처는 새 텍스처(원본 UV 해상도와 같은 크기)에 자동 배치. 모자라면 한 장 더(`_detail2`).
| 종류 | 칠하는 법 | opts |
|---|---|---|
| `cloth` | 불규칙 세로 주름(어두운 줄+밝은 줄), 찢어진 밑단(투명) | `hem`, `hem_depth`, `folds` |
| `metal` | 윗줄 반짝임, 아랫줄 어둡게, 5px 이상 면 모서리 징 | `rivets` |
| `plain` | 맨살·뼈·나무: 가운데 살짝 밝게 + 얼룩 | |
| `hair` | 세로 가닥, 들쭉날쭉 끝 | `hem_depth` |
| `glow` | 테두리 없이 가운데로 갈수록 밝게 | |
| `dark` | 구멍·그림자 속 (계단 1.5칸 어둡게) | |
공통 opts: `grad`(옆면 위→아래 밝기 차, 0.16), `center`, `noise`, `edge`(테두리 칸 수, 1.0), `shift`(계단 이동).

## 4. 시험에서 배운 것 (사당의 망령 1·2차, 2026-11-14)
- 두건 윗면을 머리보다 큰 판으로 두면 **모자 뚜껑**처럼 보인다 → 머리를 감싸는 껍데기(얼굴 쪽 `north`·아래 `skip`) + 차양 + 뒤로 처진 끝.
- 소매를 통짜 상자로 두면 둔하다 → 위는 팔보다 1칸 크게, 아래는 넓게(두 단) + 끝 띠.
- 같은 간격 주름은 줄무늬처럼 보인다 → 불규칙 간격, 어두운 줄 옆에 밝은 줄.
- 몸통 망토를 길게 두면 다리가 뒤로 휘두를 때 뚫는다 → 허리까지.
- 매단 등불은 공격 때 팔과 함께 막대처럼 앞으로 뻗는다(엔진에 물리 없음) → 손잡이를 쥔 모양이 낫다.
- 텍스처만 다시 칠해서는 형태가 단순한 모델이 기준 모델처럼 보이지 않는다. 다시 칠하기는 원래 색 유지(`adjust`)가 기본.
- 결과 수준: 실루엣·디테일 수치는 기준 근처까지 오지만(큐브/키 4.5 → 18.6), 재질 대비(뼈·쇠·가죽 섞임)와 디자인 완성도는
  기준 모델보다 한 단계 아래 → **보스·정예는 사람 판정과 GUI 다듬기를 전제**로 한다.
