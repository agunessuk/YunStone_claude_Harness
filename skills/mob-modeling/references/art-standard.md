# 아트 기준 (몹·보스 모델)

근거: 2026-11-14 조사 — 보유 몹·보스 67종 파일 수치(`metrics.py` 와 같은 정의), Blockbench Minecraft Style Guide,
Faithful 가이드, ModelEngine 공식 위키. 공식(Mojang) 수치 기준은 없다 → **프로젝트의 기준 모델에서 뽑는다.**

## 1. 무엇이 "따로 놀아" 보이게 하나 (측정 결과)
- 해상도(텍셀 밀도)는 대부분 이미 같다: 67종 중 55종이 인게임 16 px/블록. 차이는 **칠하는 방식과 큐브 밀도**.
- 기준 모델(해골 3종)에서 새 모델이 벗어난 정도 순: 명암 폭 > 면 테두리 어두움 > 높이당 큐브 수 > 노이즈 > 명도 > 채도 > 색 수 > 밀도.
- 다만 밀도가 튀는 소수(56.5·33·31 px 또는 5.3·8.9 px/블록)는 한 화면에서 가장 먼저 눈에 띈다 → 1순위로 고친다.
- 텍스처만 다시 칠해서는 단순한 모델이 기준 모델처럼 보이지 않는다(시험: 망령 2종). 형태 보강이 필요하다.

## 2. 기준 모델 정하기
1. 서버에서 플레이어가 가장 자주 보는 몹(여러 던전에 나오는 일반 몹)을 고른다.
2. `metrics.py <기준 모델들>` 로 잰다. 각 항목의 기준 범위 = 기준 모델 값 주변 + 보유 분포의 중간 50%.
3. `작업/모델링/기준.json` 의 `ranges` 에 적는다. 바꾼 이유를 `_설명` 에 남긴다.
4. 기준 모델 자체가 검사(`lint.py`)를 통과하는지 먼저 본다.

## 3. 기준 수치 (기본값 = 해골 3종 맞춤, 사용자 확정 전 제안)
| 항목 | 기준 | 데이터 |
|---|---|---|
| 인게임 밀도 | 16 px/블록 ±10% (±25% 밖 불합격). 키 10블록 넘는 레이드 보스만 8 이상 승인 예외 | 67종 중 55종이 16 |
| 모델 안 밀도 혼합(믹셀) | 중앙값 ±25% 밖 넓이 ≤10%. 살짝 부풀린(inflate) 겹 레이어만 예외 | 47종 모두 균일 |
| 통째 확대·축소 | UV 를 편 뒤 모델 전체 크기 변경 금지(소수 크기 큐브 ≤10%) | 이탈 모델은 92~100% |
| MythicMobs 배율 | 0.9~1.1 (무작위 배율도 이 안) | 배율 s 는 밀도를 16/s 로 바꾼다 |
| 본체 텍스처 | 2의 거듭제곱. 일반 64~128, 정예 128, 보스 256~512. 본체 1장 + 발광 1장 | 보유 분포 |
| 색 수(픽셀 95%) | 10~20, 재질당 4~6단 | 기준 12~16 |
| 평균 명도 V | 0.40~0.65, 어두운 테마도 ≥0.30 | 기준 0.60~0.64 |
| 명암 폭(밝기 표준편차) | 0.15~0.25 | 기준 0.19~0.25 |
| 노이즈(이웃 밝기차) | 0.05~0.10. 무작위 잡음으로 채우지 말고 재질 무늬로 | 기준 0.086~0.099 |
| 면 테두리 어두움 | ≥0.35 (1px 를 재질의 그림자색으로, 순흑 금지) | 기준 0.49~0.69 |
| 높이 1블록당 큐브 | 사람형·갑옷형 ≥20. 단순함이 의도인 몹(슬라임·불꽃)은 라인업 판정 | 기준 30~42, 새 일반 몹 중앙 7.8 |
| 렌더 뼈(큐브 든 뼈) | 일반 6~12, 정예 12~25, 보스 25~50 (공식 수치 없음, 추정) | `engine-rules.md` 3장 |

## 4. 사용자가 정할 것 (정하기 전 기본값)
| 결정 | 기본값 |
|---|---|
| 디테일을 기준 모델 쪽으로 올릴지, 어떤 형태에 적용할지 | 올린다. 사람형·갑옷형 일반 몹부터 |
| 테두리를 기준 모델 수준으로 맞출지, 기준 모델을 낮출지 | 맞춘다 |
| 레이드급 보스 밀도 예외, 보스 크기 등급 | 키 10블록 넘는 보스만 8 px/블록까지. 일반 보스 4~6블록 |
| 회전 규칙 밖 큐브 판정 | 인게임 확인 전까지 경고 |
| 외부 GitHub 코드(헤드리스 Blockbench MCP 등) 실행 | 하지 않음 (승인 받으면 두 번째 의견으로만) |

## 5. 분업
| 작업 | 맡는 쪽 | 한계 |
|---|---|---|

| 성긴 텍스처 밀도 올리기 | 코드는 격자·1px 구조만 | 표면 다시 그리기는 사람·GPT |

| 컨셉 시트·재질 견본 | GPT (사용자 경유) | 시안 고르기는 사람 |
| 커스텀 몹 UV 텍스처를 AI 로 통째 | 하지 않음 | AI 는 면별 UV 배치를 모름 |
| AI 3D 메시 → 큐브 몹 | 참고 그림까지만 | 고밀도·리깅 불가·라이선스(Hunyuan3D 는 한국 제외) |

## 6. 예외 기록
- 예외는 `작업/모델링/예외.md` 에 모델·항목·이유·승인자·날짜로 남긴다(Faithful 방식). 같은 예외가 같은 이유로만 반복되게.
- 구매 판단: 판매처의 "16x" 표기는 1차 필터일 뿐. 받으면 바로 `lint.py` + 라인업. Hytale 겸용 모델은 32 px/블록일 수 있다.
