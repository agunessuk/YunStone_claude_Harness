# Claude 데스크톱 운영

이 사용자는 PC에서 세션을 여러 개(교재 시리즈별, 학생관리, 표지 등) 띄워 두고 **폰으로 원격 제어**하며 일한다. 그래서 원격 제어·세션 찾기 요청이 아주 잦다.

## 원격 제어 켜기 ("리모트컨트롤 켜줘")
- 세션 관리 도구로 **지금 세션**의 원격 제어를 켠다. 결과를 한 줄로: 켜짐 / 이미 켜져 있음 / 실패와 이유.
- "폰이나 claude.ai에서 시작된 연결이라 계속 켜져 있다"는 답이 오면: 이미 켜져 있고 끌 필요가 없다고 알린다. 끄려면 세션을 끝내야 한다.
- 여러 세션을 한꺼번에 켤 때, **쉬고 있는 세션은 메시지를 한 번 받아야 켜진다**는 거절이 올 수 있다. 그때 선택지를 준다.
  1. 사용자가 PC에서 각 세션에 한 줄("확인") 보내기
  2. Claude가 각 세션에 "원격 제어 연결용 메시지입니다. 아무 작업도 하지 말고 '확인'이라고만 답해 주세요"를 보내고 다시 켜기(세션마다 짧은 답 한 번 = 사용량 조금)
- 다른 세션에서 위 문구가 오면: 아무 작업도 하지 않고 '확인'만 답한다.
- PC 앱을 껐다 켜면 원격 제어가 꺼질 수 있다고 알려 둔다.

## 세션이 안 보일 때
1. **어디서 보는지 먼저 가른다.** PC 화면에 지금 떠 있는 세션과 대화 위치로 짐작하되, 모르면 묻는다.
   - **폰·웹**: 원격 제어가 켜진 세션만 보인다 → 켜진 세션 목록을 보여 주고 나머지를 켜 줄지 묻는다.
   - **PC 사이드바**: 필터(기간·폴더)·묶음 방식을 확인하고 "전체"로 바꿔 준다. 보관(아카이브)한 세션은 목록 위 정렬 메뉴의 전체 보기 페이지에 있다.
2. 세션 목록을 **폴더별 표**로 보여 준다(제목은 눌러서 바로 열리는 링크, 마지막 작업 시각은 한국 시간).
3. 지워진 게 아니면 "지워지지 않았다"를 먼저 말한다.
- 폰 화면은 Claude가 볼 수 없다 → 바꾼 뒤 "폰 앱을 당겨 새로고침" 안내 + **미확인** 표시.

## 새 세션으로 넘기기 ("새 세션 열어줘")
- 사용자가 "새 대화에서 진행할 거야"라고 하면 지금 세션을 정리하고 새 세션을 연다. 새 세션 첫 지시에는 배경(무엇을, 어디서, 확정된 결정, 하지 말 것)을 적어 이전 대화를 몰라도 시작할 수 있게 한다. 긴 인계면 `handoff-pack`.
- 새 세션에서 결과가 오면 결과물(파일·변경)을 직접 확인한 뒤 사용자에게 전한다.

## 끊긴 뒤 이어 하기
- "사용량 제한에 도달했지만 지금은 초기화되었습니다"·"이어서 진행해"·"클로드를 종료하면서 멈춘 것 같아" → `resume-work`: `PROGRESS.md`와 실제 파일로 마지막 지점을 찾고, 백그라운드 작업(인디자인 조립, 서버)이 남아 있는지 먼저 본다.
- 끊긴 작업이 외부 프로그램(인디자인 등)을 띄운 채였으면, 그 프로그램이 멈췄거나 대화상자("마지막 저장 버전으로 되돌리시겠습니까")에 걸렸는지 확인한다. 대화상자는 무엇을 누를지 사용자에게 먼저 말한다.

## 새 PC에 하네스 설치
- 순서는 하네스 README의 설치 프롬프트를 따른다. git·Python 3가 없으면 **설치하지 말고 먼저 알린다**. 사용자가 허락하면 winget:
  - `winget install -e --id Python.Python.3.12 --scope user --override "/quiet InstallAllUsers=0 PrependPath=1 Include_launcher=1"`
  - Git은 관리자 권한 창이 뜬다. 창이 취소되면 `--override "/VERYSILENT /NORESTART /CURRENTUSER /SUPPRESSMSGBOXES"`로 다시.
  - 설치 뒤 같은 셸에서는 PATH가 안 바뀐다 → `$env:Path = [Environment]::GetEnvironmentVariable('Path','User') + ';' + [Environment]::GetEnvironmentVariable('Path','Machine')`.
  - `python`이 Microsoft Store로 연결되는 바로가기(`WindowsApps\python.exe`)면 진짜 Python이 아니다(버전이 안 나옴).
- **Git을 설치하기 전에 열린 세션**에서 하네스를 설치하면, 그 세션은 훅을 Git Bash 대신 PowerShell로 돌려 모든 명령이 막힐 수 있다. 훅은 고치지 않는다. 설치를 끝낸 뒤 **앱을 완전히 껐다 켜서 새 세션**에서 `python install.py --check`와 시험을 돌리라고 안내한다(새 세션에 붙일 지시문을 본문에 준다).
- 하네스 저장소에는 사용자 허락 없이 커밋·push하지 않는다.

## 보고 형식
- 세션 상태는 표(세션 | 결과). 링크로 열 수 있게.
- 확인할 수 없는 것(폰 화면, 사용자 PC의 다른 창)은 미확인으로.
