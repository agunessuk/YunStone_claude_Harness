# 교재 제작 흐름과 폴더·데이터 설계

## 폴더 구조 (권장 뼈대)
```
템플릿보관소/{교재}/{교재}.indd   [보호·읽기 전용] + 링크/ + 명세.md
외부자료/{교재}/{개념|문제}/{과목}/{NN_단원}/   받은 PDF 복사본 + 자른 결과 + CSV
교재제작/{과목}/{교재}/
    원고목록.csv · 단원진행.csv · 문항번호표.csv
    2_작업본/{작업자}/{과목}_{교재}_vNN_{작업자}.indd   ← 인디자인은 여기서만
    4_출력/   단원 검토 PDF
도구/설정/*.csv (과목·단원·레이아웃 숫자) · 도구/스크립트 · 도구/인디자인스크립트 · 도구/글꼴
보관소/원본백업 [보호] · 보관소/정리된파일 (지우지 않고 옮기는 곳)
```
- 폴더는 손으로 만들지 말고 설정 CSV → 초기화 스크립트로 만든다. 과목·단원 이름이 바뀌면 CSV만 고친다.
- 보호 구역은 훅으로 막고, 템플릿 파일은 읽기 전용 속성까지 건다.
- 지우는 대신 `정리된파일/{날짜-시간}_{사유}/`로 옮긴다.

## 이름 규칙
- 이름 규칙은 **두 곳에서만** 정의한다: PowerShell 공통 모듈의 이름 표와 JSX 공통 모듈의 이름 표. 하나를 바꾸면 다른 하나와 실제 폴더도 같이 바꾼다.
- 한글 이름은 NFC로 맞춘다(맥에서 온 파일은 NFD일 수 있음). 비교할 때도 NFC로 바꾼 뒤 비교.
- 작업본 `{과목}_{교재}_vNN_{작업자}.indd`, 확정본 `{과목}_{교재}_확정본.indd`. 버전을 올릴 때는 새 파일로 복사(덮어쓰지 않음).
- 단원 자료 머리 `{교재코드}_{과목}_{NN}` → 문항 `…_001.png`, 해설 `…_001_해설.png`.

## CSV 설계 (한 줄 = 한 항목, UTF-8 BOM)
| 파일 | 한 줄 | 꼭 있어야 할 칸 |
|---|---|---|
| 문항목록.csv | 자른 문항 하나 | 번호, 문항파일, 해설파일, 문제쪽, 해설쪽, 정답, **문항영역·해설영역(pt)**, 메모 |
| 재배치목록.csv | 줄 이은 문항의 조각 하나 | 번호, 배율, 조각, 쪽, x, y, 폭, 높이, 놓을x, 놓을y, 기준선, 가운데 |
| 문항분류.csv | 문항 하나의 유형 판단 | 번호, 유형, 세부꼴, 난이도, 대표후보, 근거 |
| 원고목록.csv | 교재에 들어갈 순서 한 칸 | 순번(단원×10000+10 단위), 단원, 구분(개념·문제·대표…), 캡쳐파일, 정답, 출처표기, 상태 |
| 문항번호표.csv | 조립 결과 | 단원, 교재번호, 쪽, 원래 문항, 정답 → 정답과 풀이가 이 순서로 만듦 |
| 단원진행.csv | 단원 하나 | 단원, 상태(자료없음·조립전·검토중·컨펌), 시작쪽, 끝쪽, PDF, 컨펌일 |
| 레이아웃.csv | 숫자 하나 | 교재(여러 개면 `A;B`), 항목, 값, 설명 — 더 좁은 교재 줄이 이김 |

- 엑셀이 CP949로 저장한 CSV도 읽을 수 있게 하고(BOM 없으면 UTF-8 시도 → 실패 시 CP949), 점검 도구가 UTF-8 BOM으로 되돌린다.
- 영역 칸은 손으로 고치지 않는다. 틀렸으면 자르기를 다시 돌린다.
- 원고목록에 행을 추가할 때 기존 행을 지우지 않는다. 순번을 10 단위로 띄워 사이에 끼울 수 있게 한다.

## 한 번에 돌리는 도구 (단원 만들기)
하나의 진입점이 아래를 차례로 부르게 만든다. 각 단계는 결과가 이미 있고 입력이 더 새롭지 않으면 건너뛴다.
1. 자르기(개념 상자·문항·해설·정답) → 2. 줄 잇기 → 3. 원고 생성(원고목록에 그 단원 줄이 없거나 분류가 더 새로울 때) → 4. 배치 이미지 준비 → 5. (`-인디자인`일 때) 작업본 열기 → 조립 → 점검 → 단원 PDF → 저장 → 정답과 풀이 → 단원진행 기록.
- 매개변수는 모두 지정해서 부른다(빠지면 대화형 메뉴 대신 오류로 끝나게).
- 끝에 **'확인할 것'** 목록을 출력한다: OCR로 읽은 제목, 정답 `?`, 글씨를 줄인 쪽, 대체 글꼴로 짠 곳.

## 책 작업본 방식
- 단원마다 파일을 만들지 않고 **한 권짜리 작업본에 단원을 차례로 붙인다.** 쪽 번호가 자연히 이어진다.
- 단원 쪽 수는 짝수로 맞춘다(홀수면 MEMO 1쪽). 다음 단원은 오른쪽 쪽에서 시작.
- 단원 PDF는 그 단원 쪽 범위만 내보낸다: `4_출력/{작업본}_{NN}단원_검토_{날짜-시간}.pdf`.
- 정답과 풀이는 별도 작업본. 단원마다 [빠른 정답 표] → [문항별 풀이: 원본 해설 영역을 벡터로 2단 짜깁기, 교재 번호 붙임].

## 사람과 주고받기
- 한 단원씩: 작업 → PDF·쪽 범위·확인할 것 전달 → 컨펌 → 다음 단원.
- 규칙(모양·숫자)은 사용자가 지시할 때만 바꾸고, 바꾸면 요약 문서·가이드·CLAUDE.md를 함께 고친다.
- 확정한 하네스는 날짜 붙인 사본(도구·설정·글꼴·스킬·가이드)을 보관소에 남겨 되돌릴 수 있게 한다.
- 다른 교재 자료를 잠시 빌려 양식만 시험했으면 끝나고 원고목록을 되돌리고 시험 자료는 정리된파일로 옮긴다.
