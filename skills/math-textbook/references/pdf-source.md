# 외부 PDF 처리: 쪽 그림 · OCR · 문항 자르기 · 줄 잇기

추가 설치 없이 윈도우 내장 기능만 쓴다: PDF 렌더링 `Windows.Data.Pdf`, OCR `Windows.Media.Ocr`(한국어 언어팩 필요), 이미지 분석은 `System.Drawing` + `Add-Type`으로 넣은 C# 코드. 파이썬 numpy·Pillow가 없어도 된다.

## 쪽 그림
- `scripts/pdf_render.ps1`. 분석용 300dpi, 눈으로 보는 검수용 120~150dpi, 수식 비교는 400dpi.
- `PdfPage.Size`는 1/96인치 단위 → 폭 픽셀 = `Size.Width / 96 × DPI`.
- 픽셀 ↔ pt: `pt = px × 72 / DPI`. CSV 영역은 **pt**로 저장해야 인디자인이 바로 쓴다.

## OCR
- `OcrEngine.TryCreateFromLanguage('ko')`가 null이면 한국어 OCR이 없는 것 → OCR 없이 진행하고 알린다.
- `OcrEngine.MaxImageDimension`보다 큰 그림은 실패 → 필요한 영역만 잘라서, 글자 높이가 알맞게 줄여서 읽고 좌표를 되돌린다.
- 굵은 제목은 자주 틀린다(뺄셈 → 낼셉). 수학 용어 사전과 **자모 단위 편집 거리**로 바로잡고, 그래도 '확인할 것'에 올린다.
- 수식은 OCR로 믿지 않는다. 숫자 답·'정답' 글자 찾기 정도에만 쓴다.

## 문항 자르기 원리 (2단 문제지)
1. 쪽마다 가로 머리줄과 가운데 세로줄을 찾아 단을 나눈다. 줄이 아주 옅은 회색일 수 있다 → 밝기 문턱 160으로 못 찾으면 240으로 다시.
2. 단 왼쪽의 번호(색 글자·굵은 숫자) 위치로 문항 경계를 정한다. 문항 정보 줄(단원·정답률 같은 작은 글줄)이 번호 위에 붙어 있으면 따로 떼어 메모 칸에 넣는다.
3. 작은 번호가 여러 개 늘어선 쪽 = 빠른정답 쪽, 그 뒤는 해설 쪽. 자동 판단이 틀리면 `-문제쪽 1-9 -해설쪽 11-25`처럼 사람이 지정할 수 있게 한다.
4. 정답: 숫자는 OCR, ①~⑤는 해설 그림 속 보기 기호를 모양 비교로 고른다. 못 읽으면 `?`로 두고 '확인할 것'.
5. 결과: 문항 PNG(미리보기) + 해설 PNG + 문항목록.csv(영역 pt). 다시 자르면 이전 결과는 정리된파일로 옮긴다.

## 줄 잇기 원리 (좁은 단 → 넓은 교재 칸)
- 문항을 **글줄**로 나누고(가로 투영), 글줄을 **낱말 덩어리**로 나눈다(세로 투영의 빈칸).
- 같은 문단의 줄은 이어서 새 폭에 다시 채운다. 조각마다 원래 글줄의 **기준선(글자 아랫선)**을 새 줄 기준선에 맞추므로 글자 높이가 흔들리지 않는다.
- 배율마다 `칸 폭 ÷ 배율`로 미리 채워 둔다(예: 1, 1.1, 1.2, 1.25 …). 조립은 쪽에 들어가는 가장 큰 배율을 고른다.
- 보기 ①~⑤는 폭에 맞춰 5칸 → 3칸 → 2칸 → 1칸 중 들어가는 것으로. 보기 앞 간격 ≥ 글줄 높이 × 1.8.
- 줄을 잇지 않는 것: 가운데·들여 쓴 식, 테두리 상자, 그림. 문장이 끝나고(`구하시오.`) 다음 줄이 식뿐이면 잇지 않는다.
- `+ − =` 앞뒤에서 줄을 바꾸지 않는다.
- 그림 문항: 글·보기는 왼쪽에 좁게, 그림은 오른쪽(칸 폭의 40% 안팎까지, 너무 크면 줄임). 또는 교재 규칙에 따라 본문 아래 가운데.
- 상자 넓히기: 테두리 상자를 칸 폭으로 넓히고 안의 항목((가), ㄱ., 그냥 글)마다 줄바꿈을 풀어 다시 채운다. 매단 들여쓰기 줄은 앞 항목에 잇고, 항목 표시로 시작하면 새 항목.
- 번호 맞춤에 쓸 값을 함께 저장: 첫 줄 기준선, 첫 줄 가운데 높이, 한 줄짜리 문항 여부(첫 줄 바로 아래가 보기·그림·상자면 `한줄`).

## 잘못 보기 쉬운 것
- 굵은 한글('ㅇ', '힘')을 보기 동그라미로 오인 → 동그라미 판정은 글줄 높이 0.72~1.3배 + 가운데 글자 + 귀퉁이가 빔. 한글이 있는 한 줄짜리는 글로 본다.
- 선분 윗줄(AB 위 가로줄) 같은 얇은 띠가 따로 떨어져 한 줄로 잡힘 → 가까운 글줄에 합친다.
- 양쪽 맞춤으로 벌어진 낱말 간격 → 이을 때 보통 간격으로 고른다.
- 스캔 자료의 뒷면 비침 → 배경 밝기를 올려 하얗게(문턱 185 안팎).

## 스캔 자료에서 그림만
- 영역(mm)을 받아 300dpi로 잘라 흰 바탕 PNG로. 이 그림은 벡터가 아니므로 해상도(유효 ppi 300 이상)를 확인한다.
- 스캔 글은 다시 짜는 편이 낫다: 옮겨 적은 원고(.txt)를 교재 글꼴로 새로 조판한다(math-typesetting.md).
