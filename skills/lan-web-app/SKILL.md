# 내부망 업무 웹앱 (서버 PC 운영)

근거: 학원 학생관리 앱(FastAPI + SQLite + 빌드 없는 JS)을 개발 PC에서 만들고, 학원 서버 PC로 옮겨 운영하며 실제로 겪은 일.

## 구조 기본값
| 항목 | 기본값 | 이유 |
|---|---|---|
| 서버 | Python FastAPI + SQLite(WAL) 한 파일 DB, `uv`로 실행 | 설치 한 번, 서버 PC에 DB 서버가 필요 없음 |
| 화면 | 빌드 없는 JS(모듈 몇 개) + CSS 토큰 | 서버 PC에 Node 불필요, 고치면 바로 반영 |
| 열리는 곳 | **같은 공유기 안에서만.** 포트포워딩·터널 없음 | 학생 개인정보 |
| 개인정보 | `var/` 한 폴더(DB, 백업, 연결 열쇠, 로그) | 옮기기·지우기·백업이 한 곳 |
| 코드 반영 | 깃헙 비공개 저장소 push → 서버 PC 화면의 [업데이트 받기] | 서버 PC에서 명령을 칠 사람이 없음 |

## 개발할 때 지킬 것
- **실명은 가짜로.** 학생·학부모 이름·연락처는 테스트·샘플·인계본·외부 서비스에 넣지 않는다. 사용자가 실제 명부(xls)를 주면 운영 DB에만 넣는다.
- **표는 칸 더하기만.** 값 제한(CHECK)을 바꾸는 표 이전은 자동 백업 뒤에. 켤 때 예전 DB를 맞추는 `migrate()`를 둔다.
- **권한 검사는 한 곳**(공통 도우미)에서. 화면마다 따로 막지 않는다. 역할표(원장·실장·강사·조교·관리자)를 문서로 두고 바꿀 때 표부터 고친다.
- 확인용 서버는 **임시 DB·다른 포트**로 띄우고 끝나면 끈다. 실제 DB에 시험 계정·시험 학생을 만들었다면 보고에 적는다.
- 화면·오류 문구는 선생님이 읽는 한국어. 서버 오류 `detail`을 화면에 그대로 보여 준다.
- 큰 기능은 `docs/결정기록.md`에 번호를 붙여 적고(사용자가 고른 것 + 이유) 다시 묻지 않는다.

## 화면 품질 (이 사용자가 두 번 이상 지적한 것)
자세히: [references/ui-quality.md](references/ui-quality.md)
- 저장 후 다시 그려도 **스크롤 위치 유지**(맨 위로 튀지 않기).
- 로그인한 사람의 **내 것 먼저**(내 탭이 처음 선택, 내 반이 맨 앞). 같은 창에서 계정이 바뀌면 기억한 탭·목록을 지운다.
- 날짜 있는 일정은 긴 목록 대신 **요일 칸 안 작은 네모**, 조작은 눌렀을 때 펼침.
- 종류별 색을 화면 어디서나 같게(클리닉 파랑, 시험 노랑…), 쨍한 색 대신 옅은 파스텔.
- 시간 입력 기본값이 지금 시각(17:08 같은 값)으로 잡히지 않게. 정각·30분 단위.
- 빈 반·빈 수업을 눌러도 화면이 넘어가고 "학생이 없습니다"를 보여 준다.

## 서버 PC 운영
자세히: [references/server-pc.md](references/server-pc.md)
- 사용자에게 **접속 주소 두 개**를 첫 줄에: 서버 PC `http://localhost:포트`, 다른 기기 `http://192.168.x.x:포트`.
- 검은 창을 닫으면 꺼지는 문제 → 숨김 실행(`서버켜기.vbs`) + 끄기(`서버끄기.bat`) + 로그인 때 자동 시작(`자동시작설정.bat`). 출력은 `var/server.log`.
- 설치본은 zip + 단계별 안내문(.txt). **zip에 실제 DB가 들어가면 안내문 첫 줄에 경고**하고, 옮긴 뒤 클라우드에서 영구 삭제하라고 적는다.
- 업데이트: 깃헙 fine-grained 토큰(그 저장소 하나, Contents 읽기 전용)을 서버 PC 화면에 저장 → [업데이트 확인]/[업데이트 받기]. 받기 전 DB 자동 백업, 서버 자동 재시작.
- 서버 PC로 옮긴 뒤 개발 PC 앱에 입력하지 말라고 알린다(두 DB는 합쳐지지 않음).

## 다른 기기에서 안 열릴 때
자세히: [references/network-troubleshoot.md](references/network-troubleshoot.md). 먼저 `scripts/lan_check.ps1 -Port 8810`을 서버 PC에서 돌린다(읽기만 함).
순서: 주소(http, 포트) → 서버 PC에서 그 내부 주소로 열리는지 → 같은 공유기인지(게스트 와이파이·휴대폰 데이터 X) → 네트워크 프로필 **개인** → 방화벽 python 허용 → 포트 규칙(LocalSubnet) → 백신 방화벽 → 접속하는 쪽 브라우저의 **로컬 네트워크 접근 허용**(크롬·맥).

## 하지 않는 것
- 사용자 허락 없이 바깥(인터넷)에서 열지 않는다. "오늘 밤 시연만"처럼 허락하면 **임시 터널 하나만**, 시간을 정해 열고, 끝나면 끄고 보고한다.
- 서버 PC의 방화벽·네트워크 설정은 관리자 권한 명령을 **사용자에게 안내**한다. 대신 바꾸지 않는다(되돌리는 명령도 같이 준다).
- 커밋·push는 사용자가 말할 때만.
