# 서버 PC 설치·운영

## 설치본 만들기 (개발 PC)
- `tools/build_release.py` 같은 스크립트로 zip을 만든다: 앱 코드 + `var/`(DB를 옮길 때만) + `서버PC_설치방법.txt`(버전·DB 기준 시각 자동 기입).
- zip에 실제 DB·연결 열쇠가 들어가면 안내문 맨 위에:
  - 클라우드(구글드라이브 등)의 **개인 폴더**에 올리고, 앱의 자료실 폴더나 공유 폴더에는 절대 올리지 않기
  - 링크 공유 켜지 않기
  - 서버 PC에서 켜진 것을 확인한 뒤 클라우드에서 지우고 **휴지통에서도 영구 삭제**
- USB 대신 클라우드로 옮겨도 된다. 그 경우 위 세 줄이 꼭 있어야 한다.

## 안내문에 들어갈 단계 (사용자가 그대로 따라 하는 글)
1. zip 속성 → 보안 '차단 해제' 체크(있으면) → 압축 풀기 위치를 짧은 영문 경로로(`C:\앱이름`)
2. `run.bat` 처음 실행: "Windows의 PC 보호" → [추가 정보] → [실행]. 처음 한 번은 uv·파이썬·패키지를 받으므로 인터넷 필요, 1~5분.
3. 방화벽 창이 뜨면 **[개인 네트워크] 체크 → [액세스 허용]**. 취소하면 다른 기기에서 안 열림.
4. 켜졌는지 확인: 서버 PC `http://localhost:포트` 로그인 → 원생 수·반 수가 맞는지 → 다른 기기에서 내부 주소로.
5. 업데이트 연결(깃헙 토큰, 아래).
6. 서버 PC 설정: 절전 모드 [안 함], 자동 시작, 공유기에서 서버 PC IP 고정(주소가 자주 바뀌면).
7. 평소 쓰는 법, 안 열릴 때(network-troubleshoot.md 요약).
- 버튼 이름·메뉴 경로는 화면 글자 그대로 적는다. 사용자가 막히면 그 단계 번호로 말할 수 있게 번호를 붙인다.
- 초기 계정 아이디·비밀번호는 안내문에 쓰지 않는다. 어디서 정하는지(첫 실행 화면)만 쓴다.

## 깃헙 업데이트 연결
- 깃헙 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate
  - Repository access: Only select repositories → 그 저장소 하나
  - Permissions → Repository → **Contents: Read-only** (나머지 그대로)
  - 만료 최대 1년, 만료되면 새로 만들어 다시 넣음
- 앱의 [업데이트] 화면에 토큰 저장 → [업데이트 확인]. 오류 문구별 원인을 안내문에 표로:
  - "저장소나 브랜치를 찾지 못함 / 토큰 필요" → 토큰 없음 또는 저장소 선택 안 함
  - "깃헙이 거절" → 토큰 틀림·만료·Contents 권한 없음
  - "연결하지 못함" → 서버 PC 인터넷
- [업데이트 받기]는 DB 백업 → 파일 교체 → 서버 재시작(1분 안쪽). 수업 입력이 없는 시간에.
- 저장소를 처음 만들 때 사용자의 깃헙 로그인이 필요하면, 내장 브라우저에서 사용자가 직접 로그인·승인하게 하고 기다린다.

## 숨김 실행·자동 시작 (Windows)
- `서버켜기.vbs`: `WScript.Shell.Run "cmd /c run.bat > var\server.log 2>&1", 0` (0 = 창 숨김). 이미 켜져 있으면 브라우저만 연다. 켜질 때까지 1초마다 `http://127.0.0.1:포트/`를 확인하고, 켜지면 내부 접속 주소를 알림창으로 보여 준다.
  - **VBS 파일에 한글을 쓰면 UTF-16 LE(BOM)로 저장**해야 한다. UTF-8로 저장하면 알림창 글자가 깨진다.
- `서버끄기.bat`: 그 포트에서 LISTEN 중인 python 프로세스만 끈다(다른 python은 건드리지 않음).
- `자동시작설정.bat`: 시작프로그램 폴더(`[Environment]::GetFolderPath('Startup')`)에 `wscript.exe "서버켜기.vbs" /quiet` 바로 가기를 만들고, 다시 누르면 끌지 묻는다.
- Claude가 개발 PC에서 띄울 때는 백그라운드로 실행하고, PID·포트·로그 경로를 보고에 적는다. 끝나면 끈다.

## 백업
- 켤 때 + 하루 한 번 `var/backup/app-YYYYMMDD-HHMM.db`, 최근 60개 보관. 표 이전·업데이트 직전에도.
- 서버 PC 디스크가 고장 나면 백업까지 같이 잃는다 → 바깥(암호화) 백업을 따로 권한다.
- 서버 PC를 옮길 때는 `var/` 폴더 통째로.
