# 업무 웹앱 화면 품질 기준

학원 학생관리 앱에서 사용자가 두 번 이상 지적해 굳힌 규칙과, 한 번이지만 다른 앱에도 그대로 통하는 요청. 새 화면을 보내기 전에 이 표로 스스로 검사한다.

| 규칙 | 검사 방법 |
|---|---|
| 저장한 뒤 다시 그려도 스크롤 위치를 지킨다 | 아래쪽 줄을 고친 뒤 `scrollY`가 거의 그대로인지 |
| 로그인한 사람(원장 포함) 기준으로 '내 것'이 먼저. 남의 것은 열람 가능하되 뒤에 | 계정 둘을 새로고침 없이 번갈아 로그인해 첫 탭·첫 반이 각자 자기 것인지 |
| 날짜가 있는 일정(등원·클리닉·재시험)은 요일 칸의 작은 네모. 채점·체크·다음 일정은 눌렀을 때 펼침 | 1400×900에서 한 주 판이 스크롤 한 번 안에 보이는지 |
| 종류가 다른 칸은 어디서나 같은 색. 같은 줄의 두 종류는 색과 8px 이상 간격으로 분리 | 두 종류가 함께 나온 줄을 캡처해 색이 다른지, 다른 화면의 같은 종류와 색이 같은지 |
| 색은 옅은 파스텔. 경고(빨강)는 '안 한 것'만 표시하고, 한 것은 아무것도 띄우지 않음 | 완료 상태에서 빨간 글씨가 0개인지 |
| 탭(화면)마다 배경색을 아주 약간 다르게 해 넘어간 느낌을 준다 | 탭을 오갈 때 구분이 되는지, 과하지 않은지 |
| 시간 입력은 정각·30분 단위, 지금 시각으로 기본값이 잡히지 않게 | 새 일정 입력창의 기본 시간이 17:08 같은 값이 아닌지 |
| 빈 반·빈 수업도 눌러서 들어가지고 "학생이 없습니다"를 보여 준다 | 학생 0명 반을 눌러 본다 |
| 퇴원·휴원생은 수업 화면에서 빠진다(기록은 남음) | 퇴원 처리 후 수업 화면에 안 보이는지 |
| 조교 공용 계정은 필요한 화면(예: 등원관리)만 | 그 계정으로 메뉴 수를 센다 |
| 지움 기능을 빠뜨리지 않는다(만든 것은 지울 수 있게) | 새로 만든 항목마다 삭제 단추·확인창이 있는지 |
| 학부모 문자는 반별로 **복사해서 붙여 넣을 텍스트**로 먼저 제공(발송 연동은 나중) | 복사 단추로 줄바꿈까지 그대로 복사되는지 |

## 확인하는 법
- 브라우저 창(내장 브라우저)으로 실제 화면을 열고, 바뀐 화면을 캡처해 직접 본 뒤 보고한다.
- 권한이 다른 계정 2~3개로 같은 화면을 열어 본다(원장, 강사, 조교).
